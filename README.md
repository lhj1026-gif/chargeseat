# ChargeSeat

기기 위치를 기준으로 주변 무선 충전 스팟을 찾아보는 반응형 웹앱 데모입니다.

현재 위치 버튼을 눌러 브라우저 위치 권한을 허용하면, 현재 좌표를 기준으로 주변 데모 스팟과 거리를 계산합니다. 좌표는 브라우저 안에서만 사용하며 외부 지도 서비스로 보내지 않습니다. 브라우저 위치 기능을 사용하려면 HTTPS 또는 localhost에서 실행하세요.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 로컬 웹 서버를 사용하려면 이 폴더에서 다음 명령을 실행하세요.

```bash
npx serve .
```

주변 장소와 좌석 점유 현황은 예시 데이터입니다. 실제 상점 위치, 지도 타일, IoT 센서에는 연결되어 있지 않습니다.
